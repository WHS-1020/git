配置导入导出
--

导出配置

导出内容包括：PLC 配置、设备配置、测点配置（含倍率/偏移）与报警阈值。CSV 使用分节格式（Section 列区分 PLC / Device / Point / AlarmThreshold）。

导入配置

支持导入 JSON 或 CSV（格式与导出一致）。导入前会完整校验：设备名称是否重复、PLC 是否存在、地址格式是否正确、数据类型是否支持、测点是否重复；只要有一处错误，本次导入将整体取消，不保存任何数据，并返回具体行号与原因。

CSV 格式说明

CSV 共 26 列，首列为 Section 分节标识，其余列按分节填写对应字段：

Section必填字段示例
PLCName, Protocol, IPAddress, Port, Rack, Slot, EnabledPLC,主PLC,S7,192.168.1.10,102,0,1,1
DeviceName, Code, Enabled, Description, SortOrderDevice,1#轧机,ROLLING-01,,,,,,,,,,,,,,,,,,,,,1,,,,1
PointDeviceName, Name, PlcName, Address, DataType, Unit, 报警字段…Point,温度,,,主PLC,DB1.DBD0,Real,°C,,,,1,,,,,,,,,1
AlarmThresholdDeviceName, PointName, AlarmEnabled, HH/H/L/LL, 延时, 死区AlarmThreshold,1#轧机,油流,1,,,,8,6,2000,3000,0.5

最简单的方式：先导出 CSV，用 Excel 打开编辑后再导入，格式完全兼容。
